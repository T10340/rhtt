Règles de génération de code :

Ergonomie : Prévois des zones de clic larges (boutons massifs) et des navigations adaptées au pouce (bottom bars, drawers) pour faciliter la candidature sur smartphone.

Composants : Utilise exclusivement shadcn/ui et Radix UI pour les éléments interactifs (modales, menus, formulaires) afin de garantir une accessibilité (a11y) parfaite.

Authentification : Prépare le terrain front-end pour la connexion SSO Google de manière fluide et sécurisée.
